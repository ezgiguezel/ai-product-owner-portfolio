# FR-005: Track fit hint impact with an A/B test

| Field | Value |
|---|---|
| **ID** | FR-005 |
| **Release** | R1 – Fit Insights |
| **Priority** | Must have |
| **Story Points** | 3 |
| **Status** | Ready |

## User Story

**As a** Product Owner,
**I want** fit hints to be rolled out as a 50/50 A/B test with tracking of hint views, orders and returns per test group,
**so that** I can prove that fit hints reduce the item return rate of affected articles (hypothesis: –3 pp) without lowering PDP conversion (guardrail: ≥ 2.9 %).

## Hypothesis & Success Metrics

| | |
|---|---|
| **Hypothesis** | Showing approved fit hints on the product page reduces the item return rate of affected articles by 3 pp. |
| **Primary metric** | Item return rate of articles with an approved fit hint (group B vs. group A) |
| **Guardrail metric** | PDP conversion rate ≥ 2.9 % (no decrease vs. group A) |
| **Minimum sample size / runtime** | Defined in the experimentation tool before start (see AC5); runtime ≥ 6 weeks + 30 days return window |

## Acceptance Criteria

### AC1 – Group assignment
- **Given** a visitor opens a product page for the first time
- **When** the A/B test is active
- **Then** the visitor is randomly and persistently assigned to group A (no fit hint) or group B (fit hint) in a 50/50 split

### AC2 – Event tracking
- **Given** a visitor in group B sees a fit hint
- **When** the hint becomes visible in the viewport
- **Then** an event `fit_hint_viewed` with article ID, hint type and test group is sent to the analytics system

### AC3 – Order and return attribution
- **Given** a visitor in group A or B places an order containing an article that has an approved fit hint
- **When** the order and any returns of these order lines are processed
- **Then** each order line and return record in the data warehouse contains the field `fit_test_group` (A/B)
- **And** the A/B report shows per group: PDP sessions, conversion rate, ordered items, returned items and item return rate

### AC4 – Consent
- **Given** a visitor has not given analytics consent
- **When** they open a product page
- **Then** no fit hint and no tracking event is shown/sent, and the visitor is excluded from the test population

### AC5 – Test documentation
- **Given** the test is started
- **When** it is configured in the experimentation tool
- **Then** hypothesis, primary metric, guardrail metric, minimum sample size and planned runtime (≥ 6 weeks + 30 days return window) are documented

## Notes
- Minimum test duration: 6 weeks (returns arrive with a delay of up to 30 days).
- Backlog review 2026-11-12: 3 SP may be low for persistent assignment, event tracking and order/return attribution across systems – team to re-estimate in refinement.
