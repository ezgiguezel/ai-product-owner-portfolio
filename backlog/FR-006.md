# FR-006: Personal size recommendation for logged-in customers

| Field | Value |
|---|---|
| **ID** | FR-006 |
| **Release** | R2 – My Size |
| **Priority** | Must have |
| **Story Points** | 8 |
| **Status** | Refined |

## User Story

**As a** logged-in customer with previous orders,
**I want** to see a personal size recommendation on the product page,
**so that** I can order the size that fits me without ordering several sizes.

## Acceptance Criteria

### AC1 – Recommendation shown
- **Given** I am logged in and have kept at least 2 items in the same category within the last 24 months
- **And** I have given consent to personalized recommendations
- **When** I open a product page in this category
- **Then** I see "Your recommended size: [size]" next to the size selector
- **And** the recommended size is highlighted in the size selector

### AC2 – Based on kept and returned items
- **Given** I returned an item in size M with the reason "too small" and kept the same brand in size L
- **When** the recommendation for another item of this brand is calculated
- **Then** the recommendation is L, unless the article itself has a fit hint "runs large"

### AC3 – Size not available
- **Given** my recommended size is sold out
- **When** I open the product page
- **Then** I see "Your recommended size [size] is currently sold out" and the option to get notified when it is back in stock

### AC4 – Performance
- **Given** a recommendation is requested for a product page
- **When** the page is loaded
- **Then** the recommendation is displayed within 300 ms (p95) and the page still loads if the service does not respond

## Dependencies
- FR-001 (fit categories), FR-011 (consent)
