# FR-012: Warn when the same item is ordered in several sizes

| Field | Value |
|---|---|
| **ID** | FR-012 |
| **Release** | R3 – Order Right |
| **Priority** | Must have |
| **Story Points** | 5 |
| **Status** | Refined |

## User Story

**As a** customer who is unsure about the size,
**I want** to be informed when I have the same item in my cart in several sizes and get help choosing one,
**so that** I can avoid an unnecessary return.

## Acceptance Criteria

### AC1 – Warning in the cart
- **Given** my cart contains the same article (same color) in 2 or more sizes
- **When** I open the cart
- **Then** I see a friendly hint above the items: "You have this item in [n] sizes. Based on your data, [size] should fit you best."

### AC2 – One-click size choice
- **Given** the hint is displayed with a recommended size
- **When** I click "Keep only size [size]"
- **Then** all other sizes of this article are removed from the cart and the cart total is updated

### AC3 – Customer keeps all sizes
- **Given** the hint is displayed
- **When** I click "Keep all sizes" or proceed to checkout
- **Then** the order can be placed without any further interruption
- **And** the hint is not shown again for this article in the current session

### AC4 – No recommendation available
- **Given** no size recommendation is available for me
- **When** the cart contains the article in several sizes
- **Then** the hint shows the article's fit hint (if available) instead of a personal recommendation

### AC5 – Different colors
- **Given** my cart contains the same article in different colors but each color in only one size
- **When** I open the cart
- **Then** no multi-size hint is shown
