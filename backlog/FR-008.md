# FR-008: Size recommendation for all customers and categories

| Field | Value |
|---|---|
| **ID** | FR-008 |
| **Release** | R2 |
| **Priority** | Must have |
| **Story Points** | 40 |
| **Status** | New |

## User Story

**As a** customer, **I want** to get a size recommendation for every product in the shop, **so that** I never have to return anything because of the size.

## Description

FitRight should work for everyone – logged-in customers, guests and new customers – and in all categories: womenswear, menswear, kids, shoes, accessories, lingerie and sportswear. For shoes we also need width recommendations. For guests we could use a body scan via the smartphone camera or an AR try-on. The recommendation should also work in the app, in the newsletter and in the marketplace for partner brands. It should also consider the customer's style preferences and the weather.

## Acceptance Criteria

- Recommendation works for all customers
- Recommendation works in all categories and channels
- Customers are happy with the recommendations
