# FR-014: "Did it fit?" feedback after delivery

| Field | Value |
|---|---|
| **ID** | FR-014 |
| **Release** | R3 – Order Right |
| **Priority** | Should have |
| **Story Points** | 3 |
| **Status** | Refined |

## User Story

**As a** customer who received an order,
**I want** to quickly tell the shop how the items fit,
**so that** my future size recommendations become more accurate.

## Acceptance Criteria

### AC1 – Feedback request
- **Given** my order was delivered 5 days ago
- **And** I have consented to marketing / service e-mails
- **When** the daily feedback job runs
- **Then** I receive an e-mail asking "Did it fit?" for up to 3 fashion items of the order

### AC2 – One-click feedback
- **Given** I opened the feedback e-mail
- **When** I click "too small", "fits well" or "too large" for an item
- **Then** my feedback is saved without requiring a login and I see a thank-you page

### AC3 – Usage in recommendations
- **Given** I gave fit feedback for an item
- **When** my next size recommendation is calculated
- **Then** the feedback is taken into account in the same way as a kept or returned item

### AC4 – Returned items
- **Given** I have already returned an item with a return reason
- **When** the feedback e-mail is generated
- **Then** this item is not included in the feedback request
