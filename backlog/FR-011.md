# FR-011: Consent and opt-out for personalized size recommendations

| Field | Value |
|---|---|
| **ID** | FR-011 |
| **Release** | R2 – My Size |
| **Priority** | Must have |
| **Story Points** | 5 |
| **Status** | Refined |

## User Story

**As a** customer,
**I want** to decide whether my order, return and body data is used for size recommendations,
**so that** I stay in control of my personal data.

## Acceptance Criteria

### AC1 – Ask for consent
- **Given** I am logged in and have not yet decided on personalized size recommendations
- **When** a personal recommendation could be shown for the first time
- **Then** I see a short consent dialog explaining which data is used, with the options "Allow" and "Not now"

### AC2 – No consent
- **Given** I selected "Not now" or have withdrawn my consent
- **When** I open a product page
- **Then** no personal recommendation is shown and only non-personal fit hints (FR-002) are displayed

### AC3 – Withdraw consent
- **Given** I have given consent
- **When** I switch off "Personalized size recommendations" in my account privacy settings
- **Then** my data is no longer used for recommendations from the next page load on
- **And** my fit profile (body data) is deleted within 30 days

### AC4 – Audit
- **Given** I give or withdraw consent
- **When** the change is saved
- **Then** the consent status, timestamp and consent text version are stored for audit purposes
