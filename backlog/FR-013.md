## User Story

**As a** Category Manager, **I want** a dashboard with all return information, **so that** I can make better decisions.

## Description

The dashboard should include:
- Return rates per article, brand, category, supplier, size, color, region and channel
- Fit problems and all classified return reasons
- Comparison with last year and with competitors
- Forecast of future returns
- Recommendations which articles should be delisted
- Export to Excel and PowerPoint
- Automated supplier reports
- Effect of FitRight on returns and conversion
- CO₂ impact of returns
- Alerts via e-mail and Teams
- Mobile version

## Acceptance Criteria

- Dashboard is available in the backoffice
- All data is correct and up to date
- Category Managers like the dashboard
