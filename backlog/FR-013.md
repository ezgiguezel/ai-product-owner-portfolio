## Epic Goal

Give Category Managers (persona: Markus) article-level insight into **why** items are returned – with a focus on fit problems – so that they can identify problem articles early in the season and use the data in supplier talks.

**Linked KPIs:** Return rate (fashion, item-based), size-related returns.

## Remaining Scope (not yet split into stories)

- Return rates per article, brand, category, supplier, size, color, region and channel (beyond the first slice)
- All classified return reasons (not only fit-related)
- Comparison with last year
- Export to Excel and PowerPoint
- Automated supplier reports
- Effect of FitRight on returns and conversion (re-using FR-005 A/B test data)
- Recommendations which articles should be delisted
- Alerts via e-mail and Teams
- Mobile version

## Moved to Discovery

The following ideas were moved to the [discovery backlog](discovery.md) because they need separate data sources and validation:

- Forecast of future returns
- Comparison with competitors
- CO₂ impact of returns

## Original Story (archived)

**As a** Category Manager, **I want** a dashboard with all return information, **so that** I can make better decisions.

Original acceptance criteria: "Dashboard is available in the backoffice", "All data is correct and up to date", "Category Managers like the dashboard".
