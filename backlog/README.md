## Releases

- **R1 – Fit Insights:** Fit hints on the product page based on classified return reasons
- **R2 – My Size:** Personal size recommendations, fit profile and consent
- **R3 – Order Right:** Multi-size warning, fit feedback loop and insights for Category Management

See the [main README](../README.md) for vision, personas, KPIs and roadmap.

## Story Format

Stories follow the format *As a … I want … so that …* with acceptance criteria in *Given / When / Then*. Story points use the Fibonacci scale (1, 2, 3, 5, 8, 13, …).
