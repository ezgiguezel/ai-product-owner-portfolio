# FR-007: Explain the size recommendation

| Field | Value |
|---|---|
| **ID** | FR-007 |
| **Release** | R2 – My Size |
| **Priority** | Should have |
| **Story Points** | 3 |
| **Status** | Refined |

## User Story

**As a** customer who sees a size recommendation,
**I want** to understand why this size is recommended to me,
**so that** I can trust the recommendation and decide confidently.

## Acceptance Criteria

### AC1 – Explanation on demand
- **Given** a personal size recommendation is shown on the product page
- **When** I tap on "Why this size?"
- **Then** I see a short explanation with up to 3 reasons, e.g. "You kept 3 items from this brand in size L" or "This item runs small"

### AC2 – No sensitive data shown
- **Given** I entered my body measurements in my fit profile
- **When** the explanation is displayed
- **Then** the explanation does not show my weight or other body measurements in plain text

### AC3 – Link to settings
- **Given** the explanation is open
- **When** I tap on "Manage my fit data"
- **Then** I am taken to my fit profile and privacy settings

### AC4 – Tracking
- **Given** analytics consent is given
- **When** I open the explanation
- **Then** the event `size_reco_explanation_opened` is tracked

## Dependencies
- FR-006 (personal size recommendation), FR-009 (fit profile – referenced in AC2 and AC3)
